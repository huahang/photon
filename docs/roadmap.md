# photon 开发规划

按依赖顺序排列，靠前的先做。已完成的条目会标记为 `[x]`。

## 第一阶段：看清楚有什么

- [x] 按扩展名识别媒体类型（RAW / JPEG / HEIF / PNG / 视频 / 附属文件）
- [x] 递归扫描目录，按类型汇总数量与体积（`photon scan`）
- [ ] 按文件头（magic number）校验类型，识别扩展名与实际格式不符的文件
- [ ] 识别同一次拍摄产生的文件组（RAW+JPEG 双格式、`.xmp` / `.aae` 附属文件）

## 第二阶段：读懂拍摄信息

- [ ] 提取照片 EXIF：拍摄时间、机型、镜头、快门光圈 ISO、GPS
- [ ] 提取视频元数据：QuickTime / MP4 的创建时间与时长
- [ ] 时间来源优先级与兜底策略（EXIF → 文件名 → 文件修改时间），并标注可信度
- [ ] 处理时区问题：相机本地时间与 UTC 的换算

## 第三阶段：整理

- [ ] 归档路径模板（如 `{年}/{年}-{月}-{日}/{机型}/{原文件名}`）
- [ ] 生成执行计划并支持 dry-run 预览，确认后再落盘
- [ ] 重名冲突处理：内容相同则跳过，内容不同则加序号
- [ ] 保证 RAW+JPEG、附属文件与主文件一起移动，不被拆散

## 第四阶段：维护媒体库

- [ ] 基于内容哈希的重复文件检测
- [ ] 校验媒体库完整性（文件可读、哈希未变），发现静默损坏
- [ ] 增量导入：只处理上次导入之后的新文件
